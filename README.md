# nullrelay_

A fictional system interface for an indie game experiment portal.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Deploy `dist/` to Cloudflare Pages using build command `npm run build` and output directory `dist`.

## Add games

Edit `src/games.ts` to set game URLs.

## Lore

- **nullrelay_**: studio identity.
- **noxengine**: system authority.
- **voidsync**: anomalous process.
- **operator**: visitor pseudonym stored locally.

No analytics, account tracking, or real system access is implemented.
